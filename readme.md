# Bifract Labs

Labs for [Bifract](https://github.com/zaneGittins/bifract). Each lab is a dataset, questions, and a lab guide. Import one into your Bifract from the [Exchange](https://docs.bifract.io/exchange/), or run it in a free [GitHub Codespace](https://labs.bifract.io/001/setup/#no-bifract-yet-use-codespaces).

**The guides are at [labs.bifract.io](https://labs.bifract.io).**

## Labs

| Lab | Scenario | Size |
|---|---|---|
| [001](https://labs.bifract.io/001/) | Meridian workstation intrusion. A user pastes a command they were told to run, and an attacker takes it from there. | 2.08M events, 5 hosts, 31 questions |

The datasets are on [Releases](https://github.com/zaneGittins/bifract-labs/releases), not in the repo. Each lab's folder has its question set (answers included), the Bifract models its guide uses, and a README.

## Don't contact indicators

Attacker domains are made up and their IPs are from documentation ranges. Don't resolve or connect to anything from a dataset. The domains were unregistered when published, but someone could register them later.
