# Bifract Labs

Realistic security telemetry datasets for CTFs, analyst training, and detection engineering. Each lab is a full environment's logs with an intrusion inside, plus a question set to work through.

## Labs

| Lab | Scenario | Dataset |
|---|---|---|
| [001](labs/001/) | Meridian workstation intrusion | `bifract-labs-001.jsonl.zst` |

Datasets are attached to [Releases](https://github.com/zaneGittins/bifract-labs/releases), not stored in the repo. Each lab folder has a README and a `questions.json` (answers included).

## Safety

Attacker domains in these datasets are fictional, and attacker IP addresses come from documentation ranges. Do not resolve, browse to, or otherwise contact any indicator from a dataset. Fictional domains were unregistered when published, but someone could register them later.
