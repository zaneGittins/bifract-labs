1. 1. A fake check copies a command

    A page asks you to "verify you are human" or fix an error. It has already put a command on your clipboard.

    In the logsDNS or proxy logs show the visit. The copy itself usually isn't logged (Sysmon event 24 can, but it's rarely on).

  2. 2. You paste it into Run

    The page tells you to press Win+R, Ctrl+V, Enter. That pastes the command into the Run dialog and starts it.

    In the logsSysmon 13 Explorer writes the command to the RunMRU registry key.

  3. 3. The command runs as you

    Often it's PowerShell in a hidden window. It downloads the next stage and starts it.

    In the logsSysmon 1 explorer.exe starts powershell.exe. Sysmon 22 PowerShell looks up the download domain.
