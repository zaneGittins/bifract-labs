# Takeaways

- **Choose stable values and relevant groups.** Counting tool names per user keeps updates from looking new and compares each user with their own history.
- **Count days, and check coverage alongside history.** Repeated events count once per day. Coverage of 1.00 still needs enough history before rarity means anything.
- **Compare, then investigate.** Pair first seen with rarity, check the workload, and test findings against known benign activity and known attacks.

The [questions](../questions.md) cover the same ground without the walkthrough. The [three checks](05-check-model.md#q012) apply to any environment's logs.
